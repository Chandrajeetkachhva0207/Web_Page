# 🌿 Herbal Plant – AI Powered React Web Application

A modern, responsive **React.js** web application designed to promote herbal plants and natural wellness. The project features a visually engaging user interface with a **full-screen video landing page**, **AI chatbot section**, **dark/light mode**, and a clean component-based architecture.

---

# 📌 Project Overview

The Herbal Plant project is a frontend web application that provides users with information about medicinal plants while offering an interactive AI chatbot experience. Built using **React**, **React Router**, and **Tailwind CSS**, the application focuses on performance, responsiveness, and an elegant user experience.

---

# ✨ Key Features

* 🌱 Modern Herbal Plant website
* 🤖 AI Chatbot interface with conversation history
* 💬 Quick suggestion buttons for faster interaction
* 🎥 Full-screen video hero section

# 🚀 Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/your-username/herbal-plant.git
```

## 2. Navigate to the Project Folder

```bash
cd herbal-plant
```

## 3. Install Dependencies

```bash
npm install
```

## 4. Start the Development Server

```bash
npm start
```

Open your browser and visit:

```text
http://localhost:3000
```

---

# 📦 Build for Production

Create an optimized production build:

```bash
npm run build
```

The production-ready files will be generated inside the **build/** directory.
